# Vector Search

## My understanding

Vector search is a way of finding information based on semantics instead of
exact matches. It converts text into high dimension vectors and compares them
to see how similar they are. Even if two sentences use different words, they
can still match if they mean the same thing.

## Why it matters

It makes search systems much smarter. Instead of only matching keywords, it can
understand context and intent. This is useful for things like chatbots,
recommendation systems, and searching large documents more accurately.

## Example

If you search: “What is a vector database used for?” The system can return
results about similarity search or semantic search, even if those exact words
are not in your question.
