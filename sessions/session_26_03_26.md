## What I understood

Triggers are automatic routines that run whenever a specific event occurs in
the database.

`FOR EACH ROW` indicates that the trigger executes once for every affected row.
During each execution, the following references are available:

- `OLD`: the previous state of the row
- `NEW`: the updated state of the row
